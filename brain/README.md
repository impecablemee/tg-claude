# brain/ — the part that compounds

Markdown, written by the agent, read by humans, versioned by git. `git log` on a
file here is the history of what the company believed about that account, and
when it changed its mind.

Everything else in this repo is plumbing to keep these files true.

- `accounts/` — one per counterparty (`_TEMPLATE.md` is the shape)
- `people/` — one per person who matters
- `decisions/` — `YYYY-MM-DD-slug.md`, what was decided and what it rules out
- `playbooks/` — how we handle a repeated situation
- `tasks/OPEN.md` — the open-asks list
- `reports/` — one file per daily run
- `CHAT_MAP.md` — which Telegram chat is what, and why
