# Каких доступов не хватает

Система пишет сюда сама, когда видит повторяющийся вопрос, на который не может
ответить без внешних данных. Человек выдаёт доступ — строка закрывается.

Система **не берёт секреты из переписки**. Если ключ засветился в чате, здесь
появится строка «отзовите его», а не молчаливое использование.
